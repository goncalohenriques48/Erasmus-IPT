# App Erasmus@IPT

# 

# A web application developed as a final degree project for the Bachelor's Degree in Computer Engineering at Instituto Politécnico de Tomar (IPT), Portugal.

# 

# \#Overview

# 

# App Erasmus@IPT is a web platform designed to digitalize and streamline the management of Erasmus+ student mobility processes at IPT.

# 

# The application centralizes interactions between students, Erasmus Coordinators, and the International Relations Office (GRI), supporting the application workflow from initial submission through post-mobility documentation.

# 

# \#Features

# 

# \#Institutional Authentication — Authentication using institutional Microsoft accounts.

# \#Role-Based Access Control — Separate access and permissions for students, Erasmus Coordinators, the International Relations Office (GRI), and administrators.

# \#Application Management — Create, submit, view, and edit Erasmus+ mobility applications.

# \#Application Approval Workflow — Review, approve, reject, or return applications for correction.

# \#Application Status Tracking — Track application progress throughout the approval process.

# \#Document Management — Upload and manage documents associated with mobility applications.

# \#Automated Notifications — Email notifications and in-app alerts for relevant status changes and pending actions.

# \#Student Profile Management — Manage student information and reuse profile data in subsequent applications.

# \#Destination Management — Browse Erasmus+ partner universities and select mobility destination preferences.

# \#Post-Mobility Management — Submit final mobility documentation and support the completion of the mobility process.

# \#Administration Dashboard — Manage institutional roles and Erasmus Coordinator assignments.

# 

# \#Technologies

# 

# \- C#

# \- .NET 10

# \- ASP.NET Core MVC

# \- Entity Framework Core

# \- SQL Server

# \- ASP.NET Core Identity

# \- Microsoft Entra ID / Office 365 authentication

# \- Razor, HTML5, CSS3, and Bootstrap

# 

# \#Architecture

# 

# The application follows a three-layer architecture:

# 

# \- Presentation Layer: Razor views, HTML5, CSS3, and Bootstrap.

# \- Application Layer: C# business logic implemented with ASP.NET Core MVC.

# \- Data Layer: SQL Server accessed through Entity Framework Core.
